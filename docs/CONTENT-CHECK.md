# Claims to confirm before they stay on the site

Written copy on a medical supplier's website is held to a higher standard than ordinary marketing: search engines, regulators and hospital buyers all read it. The text below was written for the site, and part of it may have been drafted with help from AI tools. Nothing here has been changed. Each claim needs someone at SURGICISS to confirm it is true and that you can show evidence if asked. Mark each one **confirmed**, **reword** or **remove**.

| Claim on the site | Where | What to confirm | Decision |
|---|---|---|---|
| "Class I medical device" (Universal Surgical Count Sheet Holder, Surgical Instrument Master Wrap, Quality Assurance Card, Surgical Tray Integrity Test, iBR, COVIDOT) | Product pages, product cards, search results | The device classification is a regulatory fact. Confirm it for each product and for each market you sell in, and keep the registration or listing number on file. The word "Class I" means different things in different regulations. | |
| "Early detection of low to high grade fever" and "highly sensitive red thermometer alert" (COVIDOT) | COVIDOT product page | Health claims need clinical or test evidence. Confirm the exact wording matches the approved intended use. | |
| "Case carts picked ten times faster" (Case Cart Matrix) | Software page, home slide | A number like "ten times" needs a measurement behind it: a trial, with before and after figures. If it came from one site, say so. | |
| "The first of its kind: automatic daily monitoring of crash carts" (Crash Cart Matrix) | Software page | "First" claims are hard to prove. Reword to what it does unless you can show nothing like it existed. | |
| "Impact displacement technology" that prevents holes or tears (Master Wrap) | Product page | Confirm the testing behind "prevents" (or reword to "helps reduce the risk of"). | |
| "A colour-changing card that sticks to wrapped sets" (Quality Assurance Card) | Product page | Confirm what the colour change shows and what standard, if any, it meets. | |
| "Compliantly obligated to enforce and cross-check our best practices" | Product page | Unclear wording. Say which standard or guideline you mean, or reword. | |
| "Best surgical outcomes", "best health outcomes", "best practice" | Home, products | Superlatives. Fine as a mission statement, but not as a claim of a result. | |
| "Prevent error, minimise delay, reduce unnecessary cost" | Home, about | Confirm you can describe how, with an example from a real department. | |
| "On time and on budget" | Home slide | A promise. Confirm you are willing to be held to it. | |
| Software described as "AI" or "predictive algorithms" (Sterile Matrix) | Software page | Confirm what the system really does, so the description is accurate. | |

How to use this list: go through it once with whoever knows the products. Anything that cannot be backed up is reworded or removed in `public/js/data.js` (the product and software text) and `public/js/site/pages-home.js`. Keep the evidence (test reports, registration numbers, trial figures) in a folder you can reach if a hospital or regulator asks.
